This Brick Break game was created in C# using the Unity game engine. The player controls a paddle to keep the ball in play while attempting to destroy the bricks on the screen.

The game uses Unity's component-based system to manage the different objects within the scene. C# scripts control player input, ball movement, collisions, and changes to the game state as the player interacts with the environment.

The finished Unity project was built for WebGL, allowing the game to be loaded and played directly through a web browser. This required preparing the Unity build for web deployment and integrating the resulting WebGL files into the website.
