Python Calculator

This calculator was written in Python and adapted into a web application using Flask. The project separates the calculation logic from the webpage itself, allowing the HTML interface to send user input to the Python backend and display the returned result.

The calculator supports basic arithmetic operations while also demonstrating how Python can be used server-side rather than only as a standalone desktop or console program.

Building this project involved handling form input, routing requests through Flask, separating application logic into multiple Python files, connecting HTML templates to Python, and deploying the Flask application to a web server so it could be embedded into this portfolio.
